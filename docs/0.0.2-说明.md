# 藏舟权限诊断 0.0.2

此包仅验证应用目录访问，不具备备份、Web UI、快照或恢复功能。x86-64，fnOS 1.1.8+；未经飞牛真机安装测试。可在应用中心尝试覆盖安装现有 0.0.1，覆盖升级和数据保留还未经验证，请勿在存有重要数据的环境中依赖这一假设。

0.0.2 对每个系统下发的授权目录使用系统访问检查分别报告读、写、搜索（遍历）是否允许，并尝试打开目录；不会在授权目录创建、修改或删除文件。结果只针对路径当时的目录对象，无法保证子项权限、之后实际 I/O 或备份/恢复必定成功。目录权限可能因系统 ACL、挂载、并发变更或其他因素发生变化。

测试：分别设置读写、只读，再撤销该测试目录授权；每次保存后检查 `/var/apps/cangzhou/var/diagnostic.log` 新增记录，记录是否手动重启。重点对比 `写=true/false` 和撤销后路径是否消失。日志含目录路径，分享前可脱敏。进程以系统创建的应用用户运行，未采用 root。

本机已完成编译、系统打包器构建、诊断进程输出及退出测试；未在真实 fnOS 上验证该版本。当前使用 POSIX access(2)，要求进程真实/有效 UID 一致；诊断日志展示真实和有效 UID/GID，因此仍需在实际环境核实两者是否一致。它不是安全边界。
