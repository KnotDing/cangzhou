# 藏舟 v0.4.9 测试版

## 更新内容

- 任务详情新增「历史任务」，展示每次备份的开始时间、耗时、状态、传输大小、仓库大小和手动或计划触发方式。
- 历史快照页面的返回按钮指向对应任务详情。

## 使用说明与限制

历史记录从本版本开始保存，每个任务最多保留最近 200 次；升级前未保存的历史无法补回。运行时最后一次报告的上传量可能不完整，未取得数据时显示未知。仓库大小为备份成功后统计的整个仓库对象大小，共享仓库时不代表当前任务独占空间；统计失败时显示未知。服务中断后无法确认结束时间时，耗时显示未知。

本版适用于 fnOS 1.1.3100 或以上的 x86-64 设备。升级前请等待正在运行的任务结束，安装前请核验发布页提供的 SHA256SUMS。请先使用可丢弃数据验证备份和恢复，并保留其他备份；自动测试不能代替真实设备验证。
