# 藏舟 v0.4.15 测试版

## 更新内容

- 任务详情新增「取消本次备份」；进程退出前仍保持仓库操作串行，取消结果写入历史记录。取消不暂停后续计划。
- 页面侧栏贴近窗口左侧，内容区域随窗口宽度伸缩；备份进行时，备份任务页面不再显示已等待秒数。

## 使用说明与限制

本版适用于 fnOS 1.1.3100 或以上的 x86-64 和 ARM64 设备。请选择对应架构的 FPK，并使用同一发布页的 SHA256SUMS 核验。升级前请等待正在运行的任务结束。

取消备份时快照可能已经提交，请查看历史快照确认。暂停任务仍只影响后续计划，不会暂停正在运行的备份。

取消流程通过模拟进程测试；本地 Kopia 仓库集成测试已通过。取消功能、ARM64 安装包和飞牛网关尚未在真实 fnOS 设备上验证，请先使用可丢弃数据测试并保留其他备份。
