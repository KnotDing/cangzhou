# 藏舟 0.4.6 测试说明

适用于 x86-64 飞牛、系统版本 1.1.3100 或以上；使用飞牛统一网关，以管理员身份在窗口内打开。升级会停止正在运行的任务，建议等备份结束后再安装。测试阶段请先使用可丢弃数据，并单独保存仓库加密密码。

## 安装与使用

1. 在应用中心手动安装 `cangzhou-0.4.6.fpk`，在应用设置中授予要备份的目录读取权限；恢复到源目录以外的路径时仍须遵循飞牛权限控制。应用只使用飞牛下发的授权路径，不假定 `/vol1` 可读。
2. 在目标飞牛启用 WebDAV，准备账号及可访问的上级目录。在藏舟选择「远程路径」，选择 WebDAV 并填写名称、地址、账号和密码；点击「测试连接」，确认结果后保存。测试使用只读目录查询，不创建文件，也不能证明账号具有写入权限。
3. 在首页新建任务，选择已保存的连接，填写相对仓库子目录、备份源、计划间隔和仓库加密密码。选择新建仓库时，藏舟会尝试创建不存在的目标目录；连接已有仓库不会创建目录。间隔为 0 表示手动运行。创建仓库不会立即备份。
4. 在任务列表中手动运行、暂停、编辑、删除和查看详情；从快照页面浏览或恢复。删除任务或连接不会删除远端仓库。多个任务串行执行。

HTTP 会明文传输账号密码；HTTPS 默认校验证书，可选择跳过证书校验，但此时无法确认服务器身份。WebDAV 密码和仓库密码保存在应用私有目录供自动执行，设备管理员可读取；旧连接文件也可能保留凭据。

## 共享连接

一个 WebDAV 连接可供多个任务使用。修改地址、账号、密码或证书选项后，藏舟会逐个验证关联的现有仓库；只有全部验证成功才一起更新，失败则保留原连接。正在使用的连接不能删除，请先更换关联任务。编辑时密码留空表示继续使用原密码。任务可单独修改仓库子目录和加密密码。

旧版任务不会自动关联到新保存的连接；如需共享管理，请先保存连接，再编辑每个任务并选择该连接及原仓库子目录，以“连接已有仓库”验证。测试版不保证旧版本数据兼容，升级前请保留其他备份。

## 验证范围和限制

已运行自动化测试和竞态检查，覆盖任务管理、目录授权检查、连接测试（包括自签名 HTTPS）、连接密码不由测试操作保存、共享连接更新成功及任一关联任务验证失败时整体回退。Kopia 仓库大小是整个仓库对象字节总量，并非任务独占空间。恢复文件保存到应用私有目录，ZIP 下载不包含符号链接及特殊文件。

## 0.4.3 备份进度与设置导出

## 0.4.4 设置导入、离线恢复、远程路径与限速

「设置导出」页面可以选择之前导出的 JSON 并预览导入。按编号合并，重复编号跳过；可选导入全局限速。若原文件不含密码或 SFTP 私钥，预览页可补填。新增任务会先逐个连接已有仓库，全部成功后才保存；源目录仍需在新设备重新授权。旧任务若未关联已保存连接，需在原设备上先关联连接再导出。

「备份恢复 → 离线恢复」可选择飞牛已授权目录中的 Kopia 仓库目录或 ZIP，或从浏览器上传 ZIP。仓库必须是完整的 Kopia 仓库，ZIP 可包含仓库文件或单层仓库目录，不支持加密 ZIP。需要仓库密码；仓库只读打开，选择快照后恢复到藏舟私有目录并可下载 ZIP。NAS 本地仓库不可包含符号链接或特殊文件。上传 ZIP 上限 64 GiB，解压后上限 256 GiB，并受飞牛网关及可用空间限制；关闭仓库会清理临时副本，异常中断可能留下临时文件。

「远程路径」支持 WebDAV 和 SFTP；新建任务时选择已保存连接。SFTP 支持密码或无口令私钥，必须填写目标服务器的 known_hosts 主机密钥并通过可信渠道核对；非 22 端口通常使用 `[主机]:端口 密钥类型 公钥` 格式。此版本不支持带口令私钥或 SMB。连接及仓库密码、SFTP 私钥保存在应用私有目录，导出时默认不包含，主动选择后以明文导出。

「备份限速」设置全局上传上限，任务编辑页可另设该任务上限，单位 KiB/s；0 表示不设置该层限制，同时设置时取较低值，下一次备份开始生效。此功能限制 Kopia 写入仓库的平均速度，不限制恢复下载或其他应用；Kopia 采用令牌桶，短时间可出现突发速率。设置文件可保存和恢复单任务限速，导入时可选择是否覆盖全局限速。

已通过自动化和竞态检查；使用实际 Kopia、本机 WebDAV 和 SFTP 服务验证任务创建、备份、主机密钥校验、密码和私钥认证、限速、设置导入，以及三种离线入口和恢复。尚未在真实飞牛上验证网关、授权目录、浏览器上传大小限制或长时间运行；建议先用测试数据验证。

## 0.4.5 界面更新、备份统计与目录创建

备份运行时，首页、任务详情、远程路径及离线恢复页面改用局部更新，避免整页刷新。表单内容、文件选择及正在操作的区域会保留；网络断开时会重试，重新连接需要飞牛登录。

备份成功后会自动统计整个仓库的对象大小，统计失败不会影响备份成功状态，并会保留上次成功的大小和时间。

选择“新建仓库”时，将检查 WebDAV 或 SFTP 目标目录并尝试创建缺失的目录；需要目标账号具有创建权限。选择“连接已有仓库”时不会创建。若上级路径无法访问或创建失败，请检查远端路径和权限。
