# 藏舟 0.3.0 测试说明

该版本供 x86-64 飞牛测试，要求系统支持统一网关。升级会停止当前正在运行的备份；如有任务运行，请先等待结束并检查结果。测试阶段不承诺旧版本数据兼容，重要数据请另行保留。

## 任务列表与管理

- 首页按列表显示任务，可按名称、源目录或目标地址搜索；支持新建、进入详情、编辑和删除。
- 每个任务可设置独立的源目录、WebDAV 目标和计划。编辑可修改任务名称、源目录和间隔，也可验证并更新 WebDAV 连接；新连接验证失败时原连接保留。更换目标后，快照列表显示新仓库内容，旧仓库不会删除。
- 删除需要确认，只从任务列表移除，不删除源文件或目标仓库；本地任务目录和旧连接配置会保留，可能含有敏感凭据。
- 暂停后不执行新的手动或计划备份，已开始的备份不受影响。恢复后从当前时间重新计算下一次计划；间隔为 0 时仍为手动任务。多个任务串行执行。

## 任务详情

- 上一次运行显示启动及结束时间、成功/失败/状态未确认。异常停止时不能推断是否成功，请检查快照。
- 运行次数从本版本开始记录，包含已启动的成功和失败尝试；旧版本没有记录的历史显示“—”。
- 仓库大小通过 Kopia 列举仓库对象并求和；这是整个仓库的对象字节总量，不等于该任务独占空间，也不含存储服务器文件系统额外开销。详情首次打开时会尝试统计；可手动刷新，并显示统计时间。连接失败时保留上次成功值及时间，并显示错误。
- 快照浏览和恢复仍针对整个快照；下载 ZIP 不包含符号链接及特殊文件，完整恢复结果保存在应用私有目录。

## 连接和安全

HTTP 会明文传输 WebDAV 凭据；HTTPS 默认验证证书，可显式选择跳过验证，跳过后不能确认目标身份。创建任务时密码保存在应用私有目录以便自动运行，设备管理员可读取。建议使用飞牛 HTTPS、独立 WebDAV 账号与目标端独立的防误删保护。

应用在飞牛统一网关窗口内打开，要求飞牛管理员身份，并按系统 Unix Socket 对端 UID 校验 root 或 www-data。尚未对本版本真实飞牛网关做验证；同 UID 的其他本机进程属于相同信任范围。

## 验证范围

已运行本机自动化测试（含竞态检查），覆盖列表搜索、详情渲染、密码不出现在页面、暂停/恢复、运行状态和次数、损坏或大体积仓库对象列表解析、连接更新失败回退，以及运行中暂停与更新连接的竞态。本机文件仓库使用实际 Kopia 验证了备份和空间统计。

通过本机模拟飞牛网关及 rclone WebDAV，使用实际 Kopia 验证了新建两个任务、列表搜索、备份与次数记录、仓库大小、暂停/恢复、HTTP 和自签名 HTTPS 目标切换、错误凭据失败回退、删除任务保留仓库，以及重启后配置和快照仍可访问。另一种本地 WsgiDAV 模拟服务曾出现 HTTP 400 并被正确记录为备份失败；该现象不能推断真实飞牛 WebDAV 的表现。

本版本尚未在真实飞牛上安装，也未对真实飞牛网关和 WebDAV、大文件、长时间备份或网络中断做验证。安装前请先使用可丢弃测试数据。
