# 藏舟 v0.4.14 测试版

## 更新内容

- 将「远程路径」更名为「存储位置」，统一管理本地目录、WebDAV 和 SFTP；一个存储位置可供多个任务使用。
- 任务可选择本地存储位置并指定仓库子目录。新建仓库时可尝试创建缺失的子目录，连接已有仓库时不会创建目录。
- 保留旧版直接指定本地仓库目录的任务；设置导入导出支持本地存储位置。
- 本地仓库继续检查飞牛目录授权、实际访问权限、源目录与仓库的包含关系及子路径中的符号链接。

## 使用说明与限制

本版适用于 fnOS 1.1.3100 或以上的 x86-64 和 ARM64 设备。请选择对应架构的 FPK，并使用同一发布页的 SHA256SUMS 核验。升级前请等待正在运行的任务结束。

本地存储位置的根目录须事先存在，并在飞牛应用设置中授权且可读写。仓库和源数据位于同一设备时，无法抵御整机或存储故障，请保留其他备份。

本地存储位置功能、ARM64 安装包和飞牛网关尚未在真实飞牛设备上验证。请先使用可丢弃的数据测试备份和恢复。
