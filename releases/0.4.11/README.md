# 藏舟 v0.4.11

## 功能清单

- 使用 Kopia 将授权目录加密备份到 WebDAV 或 SFTP 仓库，支持新建仓库和连接已有仓库。
- 创建多个备份任务，支持手动备份、按间隔计划运行、暂停及恢复任务，支持全局和单任务上传限速。
- 查看任务运行历史、状态、耗时、传输数据和仓库大小，支持浏览历史快照。
- 在线浏览快照，跨目录选择最多 100 个普通文件或目录恢复；支持从已授权目录或上传的仓库 ZIP 进行离线恢复。
- 管理可复用的远程连接，支持 WebDAV 和 SFTP 密码或无口令私钥认证，并验证 SFTP 服务器主机密钥。
- 导入和导出任务、连接及限速设置；默认导出不包含密码和私钥。
- 分别提供适用于 x86-64 和 ARM64 的 fnOS 安装包。

## 本版调整

- 完善应用中心展示的应用描述、维护者信息和更新说明，整理安装包模板及构建、发布流程。

## 使用说明与限制

本版适用于 fnOS 1.1.3100 或以上的 x86-64 或 ARM64 设备。请下载与设备架构对应的 FPK，并使用同一发布页的 SHA256SUMS 核验。升级前请等待正在运行的任务结束。

自动测试不能代替真实设备验证；ARM64 包、飞牛网关、实际 WebDAV、大文件、网络中断及长时间运行等场景仍需进一步验证。请先使用可丢弃的数据验证备份和恢复，并保留其他备份。
