# 藏舟 0.4.3 测试说明

适用于 x86-64 飞牛、系统版本 1.1.3100 或以上；使用飞牛统一网关，以管理员身份在窗口内打开。升级会停止正在运行的任务，建议等备份结束后再安装。测试阶段请先使用可丢弃数据，并单独保存仓库加密密码。

## 安装与使用

1. 在应用中心手动安装 `cangzhou-0.4.3.fpk`，在应用设置中授予要备份的目录读取权限；恢复到源目录以外的路径时仍须遵循飞牛权限控制。应用只使用飞牛下发的授权路径，不假定 `/vol1` 可读。
2. 在目标飞牛启用 WebDAV，预先创建账号和目标目录。在藏舟选择「WebDAV 连接」，填写名称、地址、账号和密码；点击「测试连接」，确认结果后保存。测试使用只读目录查询，不创建文件，也不能证明账号具有写入权限。
3. 在首页新建任务，选择已保存的连接，填写相对仓库子目录、备份源、计划间隔和仓库加密密码。仓库子目录须在目标端预先创建；间隔为 0 表示手动运行。创建仓库不会立即备份。
4. 在任务列表中手动运行、暂停、编辑、删除和查看详情；从快照页面浏览或恢复。删除任务或连接不会删除远端仓库。多个任务串行执行。

HTTP 会明文传输账号密码；HTTPS 默认校验证书，可选择跳过证书校验，但此时无法确认服务器身份。WebDAV 密码和仓库密码保存在应用私有目录供自动执行，设备管理员可读取；旧连接文件也可能保留凭据。

## 共享连接

一个 WebDAV 连接可供多个任务使用。修改地址、账号、密码或证书选项后，藏舟会逐个验证关联的现有仓库；只有全部验证成功才一起更新，失败则保留原连接。正在使用的连接不能删除，请先更换关联任务。编辑时密码留空表示继续使用原密码。任务可单独修改仓库子目录和加密密码。

旧版任务不会自动关联到新保存的连接；如需共享管理，请先保存连接，再编辑每个任务并选择该连接及原仓库子目录，以“连接已有仓库”验证。测试版不保证旧版本数据兼容，升级前请保留其他备份。

## 验证范围和限制

已运行自动化测试和竞态检查，覆盖任务管理、目录授权检查、连接测试（包括自签名 HTTPS）、连接密码不由测试操作保存、共享连接更新成功及任一关联任务验证失败时整体回退。Kopia 仓库大小是整个仓库对象字节总量，并非任务独占空间。恢复文件保存到应用私有目录，ZIP 下载不包含符号链接及特殊文件。

另以本机模拟 WebDAV 和实际 Kopia 验证了保存前连接测试、新建两个仓库、执行备份及错误凭据时共享连接回退。

本版本尚未在真实飞牛安装和验证统一网关、实际 WebDAV、网络中断、大文件及长时间运行。请先用测试数据执行一次备份、快照浏览和恢复，再用于重要数据。同 UID 的其他本机进程处于网关信任范围内。

## 0.4.1 修复

修复浏览器安全策略阻止“测试连接”的请求。创建任务时若 Kopia 读取仓库目录返回 404，显示完整目标地址并提示检查目录和权限。已用本机 WebDAV 与实际 Kopia 复现目标子目录不存在的 404，创建子目录后成功新建仓库。真实飞牛环境仍需验证。

## 0.4.2 界面调整

侧边栏新增「备份恢复」「目录权限」「使用提示」。已恢复文件及下载入口、当前授权目录和使用提示分别显示在对应页面。

## 0.4.3 备份进度与设置导出

任务详情在该任务备份运行中显示开始时间、持续时间、已处理大小、预计总大小、预计剩余时间和进度条，页面自动刷新。已处理大小是 Kopia 报告的已哈希与复用文件大小，包含尚待完成的仓库提交，并非实际上传量；总大小及剩余时间来自 Kopia 的估计，可能波动，不可用或不可靠时显示“估算中”。

工作空间的「设置导出」下载任务和 WebDAV 连接配置 JSON，默认不包含密码；勾选后包含明文 WebDAV 和仓库密码，请妥善保管。此文件不含备份数据、快照、运行历史和 Kopia 连接配置；当前版本不支持导入，不能直接用它恢复应用。

已使用实际 Kopia 的本地仓库验证备份和进度输出读取，自动化检查覆盖进度估计及密码导出。新版本尚未在真实飞牛上验证。
