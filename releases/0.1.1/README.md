# 藏舟 0.1.1 窗口内嵌测试版

适用 **x86-64 飞牛 NAS、fnOS 1.1.3100 及以上（统一网关兼容性下限采用社区实践值，尚未实机验证）**。这是备份功能测试版，不应作为重要数据的唯一备份。尚未在真实飞牛设备上安装此版本，也未连接实际的飞牛 WebDAV 服务。

## 安装和登录

1. 在飞牛「应用中心 → 手动安装」上传 `cangzhou-0.1.1-x86.fpk`。此前权限诊断版也叫 `cangzhou`，系统可能提供升级安装；升级、卸载和数据保留行为尚未实机验证。建议在测试设备和测试目录试用。
2. 应用设置 → 授权目录，给测试源目录授权“只读”；如无授权，藏舟界面不会列出目录。权限变动回调会尝试停止并重启藏舟，正在运行的备份会被取消；此版本的回调行为尚未在飞牛验证。
3. 启动藏舟，在飞牛桌面点击图标。入口通过飞牛统一网关 `/app/cangzhou/` 在桌面应用窗口内打开，应用不再单独监听 51591 端口。藏舟登录页使用独立管理密码；优先用 HTTPS 登录飞牛，避免管理密码在网络中明文传输。统一网关需要飞牛系统支持，实际网关注册和窗口显示尚未真机验证。
4. 登录密码在源飞牛的应用私有文件中，由管理员通过终端读取：

   ```sh
   sudo cat /var/apps/cangzhou/var/admin-password
   ```

   如果不存在，先检查应用是否成功启动，以及应用中心的日志。该密码是管理凭据，不要截图或分享。应用数据目录中的 `job.json`、Kopia 配置和缓存也应按敏感资料保护；自动任务需要保存仓库密码和 WebDAV 密码，设备管理员能够读取它们。

## 配置并验证

1. 在目标飞牛准备独立的 WebDAV 账号和空目录，授予该账号所需读写权限。填写目标目录的 **HTTPS** WebDAV 地址、账号和密码，并选择“新建仓库”。目标证书必须受源飞牛系统信任；本版不提供跳过证书验证或安装自签名 CA 的界面。仅本机回环测试地址允许 HTTP。
2. 设置一个至少 12 位的独立仓库密码，并在应用外安全保存。密码丢失后无法恢复仓库。已有 Kopia WebDAV 仓库请选“连接已有仓库”，不要误选新建。每个应用目前只支持一个仓库。
3. 在任务中填写已授权根目录或其子目录的绝对路径；可参考界面列出的授权路径。填写计划间隔小时数，0 表示只手动运行。设置完成点击“立即备份”。
4. 待首页显示备份完成，打开快照，检查文件列表；点击恢复。恢复写入应用私有目录下新建的文件夹，不覆盖原目录；首页显示路径并提供 ZIP 下载。ZIP 跳过符号链接及特殊文件，完整的恢复目录仍留在应用私有空间。比较下载文件和源文件内容，再测试修改、删除源测试文件后的历史恢复。
5. 验证定时：设置一个较短间隔，确认应用保持运行时会产生新快照。停机期间到期的任务会在重启后尝试执行。检查授权撤销后的行为：禁止访问后备份应被拒绝；不应因已有任务而继续读取被撤销目录。

## 当前限制和注意事项

- 本版仅一个仓库、一个源目录任务；间隔为整小时（1–720），没有高级日历、失败通知、保留策略界面或仓库更换界面。需要更换仓库时先保全配置和仓库密码，暂不要自行删除配置文件。
- 快照浏览列出完整路径，恢复操作针对整个快照，不支持单独选择文件恢复。ZIP 不含符号链接和特殊文件；需完整保留时由管理员从恢复目录处理。
- 授权路径由 `TRIM_DATA_ACCESSIBLE_PATHS` 提供，应用以飞牛专用用户运行，不假定 `/vol1`。每次备份前重新检查源目录是否在收到的授权根内并检查当前进程访问权限；权限检查和真实读写之间仍可能发生变化，子项还可能存在拒绝访问。实际备份错误会报告失败。
- 授权变化通过系统回调重启服务并取消进行中的子进程；调度、进程停止和恢复在真正 fnOS 上尚未实测。快照内容保留在远端；撤销源目录授权不会自动删除历史快照。
- 管理界面使用藏舟独立密码；网络传输由飞牛访问方式决定，请通过 HTTPS 访问飞牛并限制网络访问。访问管理界面的所有人可以访问仓库和恢复文件，保管好管理密码。
- Kopia 默认会执行仓库维护并依照其保留策略管理快照。远端 WebDAV 账号如果有删除权限，不能提供不可变备份；目标端的独立快照、防误删除保护需要另行配置和验证。
- 如果目标 WebDAV 连接失败、应用无法启动或备份不完整，请保留脱敏的 `server.log`、界面错误和飞牛版本。不要发送账号、密码、仓库密钥、cookie 或未脱敏的私人路径。

## 验证范围

- 0.1.1 通过本机 Unix Socket 模拟网关，验证登录、路径前缀、同源嵌入安全策略、备份、快照和恢复下载；实际飞牛网关尚未验证。
- 官方 fnpack 1.2.3 构建；Kopia 0.23.1 Linux x86-64 官方发行包已核对发布校验值。
- macOS 本机通过藏舟界面连接本机 WsgiDAV，完成加密仓库创建、备份、快照列表、递归浏览、完整恢复和 ZIP 下载，恢复文件逐字节一致；登录、请求令牌和授权范围外目录拒绝测试通过；重启后到期的计划在本机执行成功。模拟 WebDAV 过程中出现 HTTP 400 连接警告，原因未确定；不能推断飞牛 WebDAV 的兼容性。
- 权限检查逻辑的本机自动测试通过；之前的诊断包在用户设备验证了只读、读写和禁止访问的变化。0.1.1 本身未实机验证，也未测试大数据量、断网恢复、并发、错误注入、授权撤销时的长任务终止或生产数据恢复。
