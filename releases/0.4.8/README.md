# 藏舟 v0.4.8 测试版

## 更新内容

- 在线快照支持逐级浏览并选择一个或多个文件、目录恢复；可以跨目录勾选，最多选择 100 项。
- 离线仓库的快照增加浏览和选择恢复入口。恢复结果保存在新的应用私有目录，保留所选项目的相对路径；未选择的项目不会被恢复。
- 调整工作空间菜单顺序，把常用操作和设置依次排列，更新 README 界面截图。
- 两个平台的发布流程使用版本说明作为发布页正文。

## 使用说明与限制

进入任务的「历史快照」，点击「浏览文件」，勾选项目后选择「恢复所选项目」；离线恢复先打开仓库，再进入快照浏览。成功后可在「备份恢复」页面下载结果 ZIP。

仅可单独选择普通文件和目录；符号链接、特殊文件及包含控制字符或反斜杠的路径不能单独选择。恢复目录时，目录内的内容由 Kopia 处理；下载 ZIP 不包含符号链接和特殊文件。单个目录的列表超过 4 MiB 时只显示前一部分，可输入目录相对路径进入子目录。

本版适用于 fnOS 1.1.3100 或以上的 x86-64 设备。升级前请等待正在运行的任务结束，安装前请核验发布页提供的 SHA256SUMS。请先使用可丢弃数据验证备份和恢复，并保留其他备份；自动测试不能代替真实设备验证。
