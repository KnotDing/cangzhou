# 藏舟 v0.4.10 测试版

## 更新内容

- 新增适用于 fnOS ARM64 设备的安装包，与 x86-64 包分别提供。
- 构建和发布流程检查安装包的平台标识和程序架构，并为两个包提供 SHA-256 校验值。

## 使用说明与限制

本版适用于 fnOS 1.1.3100 或以上的 x86-64 或 ARM64 设备。下载时请选择与设备架构对应的 `-x86.fpk` 或 `-arm.fpk`，并使用同一发布页的 SHA256SUMS 核验。升级前请等待正在运行的任务结束。

ARM64 包尚未在真实飞牛 ARM 设备上安装和测试；交叉编译及自动检查不能代替设备验证。请先使用可丢弃数据验证备份和恢复，并保留其他备份。
