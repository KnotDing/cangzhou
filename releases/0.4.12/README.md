# 藏舟 v0.4.12 测试版

## 更新内容

- 新增本地备份：可选择已授权的本地目录，新建或连接已有的 Kopia 加密仓库。
- 创建任务和更新仓库连接时支持本地目录，设置导入导出保留本地仓库路径。
- 本地仓库要求目录已存在且可读写，并检查授权及与备份源目录的包含关系。

## 使用说明与限制

本版适用于 fnOS 1.1.3100 或以上的 x86-64 和 ARM64 设备。请选择对应架构的 FPK，并使用同一发布页的 SHA256SUMS 核验。升级前请等待正在运行的任务结束。

请先在应用设置中授权源目录和本地仓库目录；两者不能相同或互相包含。仓库和源数据位于同一设备时，无法抵御整机或存储故障，请保留其他备份。

本地仓库功能尚未在真实飞牛设备上验证，ARM64 包和飞牛网关也仍需设备验证。请先使用可丢弃数据测试备份与恢复。
