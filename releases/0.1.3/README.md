# 藏舟 0.1.3 测试版

适用于 x86-64 飞牛 NAS；安装包要求 fnOS 1.1.3100 或更高版本，且系统必须支持统一网关。网关最低版本采用社区实践值，尚未对不同版本实机验证。请先使用测试数据，本版不应作为重要数据的唯一备份。

## 升级和打开

1. 在应用中心手动安装或升级 `cangzhou-0.1.3-x86.fpk`。本包和之前版本使用相同应用名，理论上会保留应用数据；升级、数据保留及网关重新注册尚未在飞牛真机验证。
2. 用飞牛**管理员**账号登录飞牛桌面，点击藏舟图标。页面应在飞牛窗口内打开，不再要求输入藏舟管理密码；此前生成的 `admin-password` 文件不会自动删除，但新版不再使用它。
3. 若未配置仓库，选择新建或连接已有仓库，填 WebDAV 地址、账号、密码及仓库加密密码。新建仓库请选空目录。仓库密码务必在应用外另行安全保存，丢失后无法解密备份。
4. 在飞牛应用设置授权测试源目录（备份可使用只读），再在藏舟中选择或输入该目录，保存计划并点击立即备份。从历史快照恢复后，检查恢复结果和 ZIP 下载内容。

## 仓库连接状态

新建或连接仓库后，概览会显示“正在连接仓库”、等待秒数，并约每 3 秒刷新一次。这个过程需要 Kopia 检查 WebDAV 仓库，最长等待 5 分钟；进行中打开历史快照会返回概览，不会再显示含糊的“已有任务运行”。完成后显示连接结果；失败或超时会释放任务状态，并在概览显示错误。

升级时正在运行的连接会被停止。若之前新建操作已在目标目录创建了仓库，新建重试可能提示目录已有数据；确认已有仓库和密码后选择“连接已有仓库”，不要删除目标目录来排除此问题。

## WebDAV 连接方式

- **HTTP**：地址以 `http://` 开头，可直接连接。WebDAV 账号、密码和请求内容会在网络上明文传输；Kopia 仓库的数据在源端加密，但 HTTP 不能保护连接凭据和传输元数据。
- **HTTPS，验证证书**：默认方式，目标证书需受源飞牛信任。
- **HTTPS，跳过验证**：仅在需要时勾选“HTTPS 跳过证书验证”。该方式仍加密链路，但不验证对端身份，可能连接到冒充的服务器；仅用于你信任的网络。

由于 Kopia 原生 WebDAV 后端没有该选项，跳过验证时藏舟会启动一个仅监听本机回环地址的 WebDAV 代理。Kopia 使用随机生成的独立代理凭据，代理才向目标服务器提供真实 WebDAV 凭据；代理端口、代理凭据和目标凭据保存在应用私有数据中，服务重启会恢复代理。目标地址和仓库一旦配置，本测试版暂不支持在界面切换仓库或编辑连接信息。

## 权限与安全

- 应用通过 `/app/cangzhou/` 统一网关进入；服务仅监听应用目录下 Unix Socket，没有对外的管理 TCP 端口。藏舟要求内核提供的连接 UID 是 root 或系统 `www-data`，且网关身份头表明当前用户是飞牛管理员。你提供的进程列表显示当前设备的飞牛 nginx 工作进程使用 `www-data`；网关实际连接身份尚未在真机确认。若设备使用其他账户，页面会拒绝访问，需根据设备情况适配。
- `www-data` 是共享的本机账户；同样以该账户运行、能连接 Socket 的其他本机进程属于相同信任范围，不能仅凭 UID 区分不同进程。正常网络请求仍须经过飞牛网关的登录校验。不要将应用 Socket 或身份头直接暴露给网络。
- 建议通过 HTTPS 登录飞牛；登录飞牛时使用 HTTP，飞牛会话及界面提交的 WebDAV 凭据可能被网络中的其他设备读取。
- 源目录由飞牛授权路径和应用用户的实际文件权限共同限制。修改授权会触发应用回调，停止并重启服务；正在进行的备份会被取消。长任务中撤销授权的效果尚未在真机验证。
- 凭据保存在应用私有数据目录，以便自动任务运行。设备管理员可读取，且目标 WebDAV 有删除权限时不能防止备份被删除；请在目标端另外配置并验证防误删除保护。

## 测试步骤与限制

1. 测试 HTTP 目标：创建空仓库，备份一组可丢弃文件，浏览快照并恢复比对。
2. 测试自签 HTTPS：先不勾选跳过验证，应连接失败；勾选后重新连接，测试备份、恢复、重启后再备份。
3. 把一个测试目录从读写改为只读，再改为禁止访问；确认界面显示、备份及恢复行为符合预期。授权回调期间不要依赖该备份是完整的。
4. 目前只有一个仓库和一个源目录任务；快照浏览为递归文件列表，恢复为整个快照。ZIP 不包含符号链接或特殊文件，完整恢复结果留在应用私有目录。计划按小时运行；没有通知、保留策略界面、增量进度或图形化目录树。

## 已验证范围

- 在本机模拟网关中验证了管理员身份头、非管理员拒绝、未授权请求拒绝和 CSRF 检查；Linux 安装包已编译，**内核对端 UID 验证及飞牛网关头尚未在真实飞牛上测试**。
- 本机慢速 WsgiDAV 测试中，HTTP 创建仓库时访问历史快照会返回带进度的概览，完成后可备份和访问快照；自签名 HTTPS 默认拒绝，勾选后创建仓库、备份、恢复并逐字节对比成功，重启后再次备份成功。先前模拟 WebDAV 曾出现 HTTP 400 警告，实际飞牛 WebDAV、大文件、断网及长期使用尚未测试。
- 在本机浏览器检查了桌面和窄窗口布局；真实飞牛窗口、应用升级以及连接飞牛目标 NAS 尚未验证。
